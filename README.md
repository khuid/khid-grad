# KHID 연도별 졸업전시 사이트

`khid.grad.khu.ac.kr` — 주소는 하나지만 `/2026`, `/2027`처럼 경로로 연도를 나눕니다.
**각 연도는 서로 다른 사이트입니다.** 디자인·작품·졸전자·기획·인터랙션이 매년 달라지므로, 한 연도를 고쳐도 다른 연도에는 아무 영향이 없어야 합니다.
(역대 포스터를 모아 둔 전체 아카이브 사이트 `khid.exhibit.khu.ac.kr`는 별도 프로젝트 `archive-site`)

이 사이트의 모든 것은 아래 둘 중 하나입니다.

- **공통 규칙**: 매년 똑같이 적용되는 것. 이 문서에 적힌 것만 공통이고, 바꾸면 **모든 연도가 같이 바뀝니다.**
- **연도별**: 그 밖의 전부. 각 연도 폴더 안에만 두고, 다른 연도와 절대 공유하지 않습니다.

> 이 목록에 없는 것은 공통이 아닙니다. "작년에 이렇게 했으니 올해도 그렇겠지" 하고 가져다 쓰지 말고, 필요하면 그 연도 폴더 안에 새로 만드세요.

---

## 공통 규칙 (모든 연도)

| 무엇 | 어디 | 내용 |
|---|---|---|
| 주소만 입력했을 때 | `src/app/page.tsx` | `/`로 들어오면 **가장 최신 연도**로 이동. 새 연도를 추가할 때만 바꿈 |
| 없는 주소 안내 화면 | `src/app/not-found.tsx` | `/2025`처럼 없는 주소 → "페이지를 찾을 수 없어요" + 최신 전시·아카이브 링크. 어느 연도에도 속하지 않아 일부러 기본 글꼴·흑백 |
| 가장 바깥 틀 | `src/app/layout.tsx` | 언어(한국어), 링크 미리보기 주소 기준, 기본 제목. 바탕색·글꼴 등은 **넣지 않음** |
| 화면 튕김 방지 | `src/app/_common/common.css` | 휴대폰에서 맨 위·아래 바운스 끔(카카오톡 덜컹거림 방지) |
| 이미지 저장 방지 | `src/app/_common/common.css`, `CopyGuard.tsx` | 이미지·영상 우클릭/끌기/길게 눌러 저장 막기, 배포 사이트에서 개발자 도구 단축키 막기 |
| 이미지 최적화 | `next.config.ts` | 지원 브라우저엔 AVIF, 아니면 WebP로 자동 변환 |
| 폰트 경량화 도구 | `scripts/subset-fonts.py` | 도구만 공통. **연도를 지정해서** 그 연도 폰트만 만듦 (아래 참고) |
| 프로그램 버전 | `package.json` | Next.js 등. 올리면 모든 연도가 영향 → 올린 뒤 **지난 연도 페이지도 전부 확인** |

공통 규칙을 바꾸거나 새로 추가할 때는 이 표도 같이 고치세요. 표에 없으면 공통이 아닙니다.

## 연도별 (절대 섞지 않음)

연도 `YYYY`의 모든 것은 아래 폴더에만 있습니다. 다른 연도 폴더의 파일을 불러오거나(import) 고치지 않습니다.

| 폴더 | 들어 있는 것 |
|---|---|
| `src/app/YYYY/` | 그 연도 페이지 전부, 화면 부품(`_components/`), 데이터(디자이너·작품·졸준위), 공개 전 커밍순 설정 |
| `src/app/YYYY/layout.tsx` | 폰트, 링크 미리보기(카톡·인스타 썸네일), 그 연도 스타일 불러오기 |
| `src/app/YYYY/YYYY.css` | 색, 바탕색, 글자 크기 규칙, 애니메이션 등 스타일 전부 |
| `src/app/YYYY/icon*.ico·svg`, `apple-icon.png` | 파비콘(브라우저 탭 아이콘)·홈 화면 아이콘 |
| `public/YYYY/` | 그 연도 이미지·영상·폰트(`fonts/`) |
| `fonts-src/YYYY/` | 그 연도 폰트 원본 |
| `scripts/YYYY/` | 그 연도에만 쓰는 도구 (예: 2026 프로필 사진 자르기 규칙) |

- **스타일이 섞이지 않는 이유**: `YYYY.css`는 그 연도 페이지에서만 불러오고, Tailwind도 그 연도 폴더 안의 코드만 읽도록 맨 위에 `@import "tailwindcss" source(none); @source "./";`를 둡니다. 그래서 2027이 `key` 같은 같은 색 이름을 써도 2026과 섞이지 않습니다. 새 연도 css에도 꼭 이 두 줄을 넣으세요(Tailwind를 쓰는 경우).
- **연도 사이를 오가는 링크**는 `<Link>` 대신 일반 `<a>`로 거세요(페이지를 새로 불러와서 앞 연도의 스타일이 남지 않음).

## 새 연도 추가 (예: 2027)

1. `src/app/2027/`, `public/2027/`를 새로 만듭니다. 2026 폴더를 복사해서 시작해도 되지만, 복사한 뒤 **색·폰트·파비콘·데이터·공개 날짜를 전부 2027 것으로** 바꾸고, 쓰지 않는 것은 지웁니다.
2. `src/app/2027/layout.tsx`에서 `./2027.css`를 불러오고, 2027 폰트(`public/2027/fonts/`)를 연결합니다.
3. 파비콘(`icon*`, `apple-icon.png`)을 `src/app/2027/` 안에 넣습니다.
4. `src/app/page.tsx`의 이동 경로를 `/2027`로 바꿉니다.
5. 이전 연도 폴더는 지우지도, 고치지도 않습니다.
6. 아카이브 사이트(`archive-site`)의 2027 정보에 링크(`https://khid.grad.khu.ac.kr/2027`)를 넣습니다.

**지난 연도(예: 2025)를 나중에 추가**할 때는 1~3만 하고, 4번(최신 연도 이동)은 바꾸지 않습니다.

## 폰트 경량화

한글 폰트는 원본이 커서 실제로 쓰는 글자만 남긴 경량본을 씁니다. 연도마다 폰트가 다를 수 있어서 연도별로 따로 만듭니다.
원본은 `fonts-src/YYYY/`(.woff2·.ttf·.otf), 경량본은 `public/YYYY/fonts/`에 둡니다. 경량본에는 기본 한글 2,350자와 그 연도 소스에 실제로 들어간 글자(이름·작품명 등)가 들어갑니다.
데이터를 **다 넣은 뒤** 한 번 실행하세요. 다른 연도 폰트는 건드리지 않습니다.
```bash
pip install fonttools brotli   # 처음 한 번
python3 scripts/subset-fonts.py 2026
```

npm install
